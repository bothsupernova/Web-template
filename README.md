# White Lotus Day Spa

Static HTML, CSS and JavaScript served by the existing Node HTTP server.

- Run locally: `npm start` (default port 3000; hosting supplies `PORT`).
- Validate JavaScript: `npm run build`.
- Run route and SEO integration checks: `npm test` (uses a temporary local port).
- Deployment: retain the existing GitHub-connected Node hosting setup.

See [SEO-AUDIT.md](SEO-AUDIT.md) for indexability decisions, verified business details, known limitations, and post-deployment Search Console steps.
